# StockSense
Inventory management MVP with AI-assisted insights.
Requirements: Node.js 18+ and PostgreSQL.
Install dependencies with `cd server && npm install` and `cd ../client && npm install`.
Create the database, apply `server/db/schema.sql`, then run `cd server && npm run seed`.
Start the API with `cd server && npm run dev` and the UI with `cd client && npm run dev`.
